Entrants write one funny line: a single sentence of at most 200 characters on any subject they like, submitted in their repository as plain text. When entries close, make.fun's house judge reads the lines two at a time and keeps the bigger laugh, weighing a real surprise at the end that still makes sense, an everyday truth people recognise, and economy of words.

This entry's line (148 bytes, one sentence, no trailing newline):

> I asked my dad how to fix the sink; he drove forty minutes, fixed it in ten, and spent three hours telling me about it, which was the actual repair.

## Run it

```sh
node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`) — nothing else: no network, no dependencies, no build
step.
